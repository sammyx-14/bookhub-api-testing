# BookHub API — Test Case Suite

**Note on Test Data:** Usernames, passwords, tokens, and IDs are generated dynamically per execution via
pre-request and post-response scripts within the Postman collection, rather than fixed per test case —
see `test-plan/Test-Plan.md` Section 3 and the Postman collection for implementation. Data requirements
are described qualitatively within each case's Steps where relevant (e.g. "a valid ISBN," "an existing
user's UUID").

| ID | Endpoint | Title | Category | Priority | Preconditions | Steps | Expected Result | Status | Defect Found |
|---|---|---|---|---|---|---|---|---|---|
| TC-001 | Create User | Verify user registration succeeds with a valid username and password | Positive | High | None | 1) Send a POST request to /Account/v1/User with a valid userName and password in the body. 2) Submit the request. | 201 status; response contains userID and username; response does not contain a password field. | Pass | |
| TC-002 | Create User | Verify registration fails when the password field is missing | Negative | High | None | 1) Send a POST request to /Account/v1/User with only userName in the body, omitting password. 2) Submit the request. | 400/406 status; response body matches the MessageModal shape (code, message). | Pass | |
| TC-003 | Create User | Verify registration fails when the username already exists | Negative | High | A user is already registered with a known username. | 1) Send a POST request to /Account/v1/User using the same username as the existing registered user. 2) Submit the request. | 406 status; meaningful error message returned. | Pass | |
| TC-004 | Generate Token | Verify token generation succeeds with valid credentials | Positive | High | A registered user exists with known credentials. | 1) Send a POST request to /Account/v1/GenerateToken with the registered user's correct credentials. 2) Submit the request. | 200 status; response contains token, expires, status, and result fields; status/result indicate success. | Pass | |
| TC-005 | Generate Token | Verify the response indicates failure when the password is incorrect | Negative | High | A registered user exists with known credentials. | 1) Send a POST request to /Account/v1/GenerateToken with the correct username and an incorrect password. 2) Submit the request. | Per Swagger, 200 status — but status/result fields should indicate failure (confirm live). | Pass | |
| TC-006 | Generate Token | Verify the JWT payload does not expose sensitive credentials | Security | High | A valid token has been generated for a registered user. | 1) Take the token from a successful GenerateToken response. 2) Split the token string on "." to isolate the payload segment. 3) Base64-decode the payload segment. 4) Inspect the decoded contents. | Decoded payload should contain only non-sensitive claims; it should not contain a password field. | Fail | DEF-001 |
| TC-007 | Authorize | Verify authorization succeeds with valid credentials | Positive | Medium | A registered user exists with known credentials. | 1) Send a POST request to /Account/v1/Authorized with the registered user's correct credentials. 2) Submit the request. | 200 status; response body is the literal boolean true. | Pass | |
| TC-008 | Authorize | Verify authorization fails for a non-existent user | Negative | Medium | None | 1) Send a POST request to /Account/v1/Authorized with a username that has never been registered. 2) Submit the request. | 404 status; error message returned. | Pass | |
| TC-009 | Get User | Verify user details are returned for a valid UUID with a valid token | Positive | High | A registered user exists and a valid token has been generated for that user. | 1) Send a GET request to /Account/v1/User/{UUID} using the registered user's UUID. 2) Attach a valid token to the Authorization header. 3) Submit the request. | 200 status; userId and username in the response match the registered user; books array is empty for a newly created user. | Pass | |
| TC-010 | Get User | Verify the request fails when no token is attached | Negative (auth) | High | A registered user exists. | 1) Send a GET request to /Account/v1/User/{UUID} using a valid user's UUID. 2) Do not attach an Authorization header. 3) Submit the request. | 401 status; error message returned. | Pass | |
| TC-011 | Get User | Verify the request fails for a non-existent UUID | Negative | Medium | A valid token exists. | 1) Send a GET request to /Account/v1/User/{UUID} using a UUID that does not correspond to any registered user. 2) Attach a valid token to the Authorization header. 3) Submit the request. | Per Swagger, 401 status (confirm live vs 404). | Pass | |
| TC-012 | Get All Books | Verify the book catalogue is returned successfully | Positive | Medium | None | 1) Send a GET request to /BookStore/v1/Books. 2) Submit the request. | 200 status; response contains a non-empty books array matching the BookModal shape. | Pass | |
| TC-013 | Get Book | Verify a single book is returned for a valid ISBN | Positive | Medium | A valid ISBN exists in the catalogue. | 1) Send a GET request to /BookStore/v1/Book with a valid ISBN as a query parameter. 2) Submit the request. | 200 status; response matches the BookModal shape for the requested ISBN. | Pass | |
| TC-014 | Get Book | Verify the request fails for an invalid ISBN | Negative | Medium | None | 1) Send a GET request to /BookStore/v1/Book with an ISBN that does not exist in the catalogue. 2) Submit the request. | 400 status; error message returned. | Pass | |
| TC-015 | Add Book to Collection | Verify a valid book can be added to a user's collection | Positive | High | A registered user and valid token exist; a valid ISBN is known. | 1) Send a POST request to /BookStore/v1/Books with the user's ID and a valid ISBN in the body. 2) Attach a valid token to the Authorization header. 3) Submit the request. 4) Send a follow-up GET request to /Account/v1/User/{UUID} to verify the collection. | 201 status; follow-up Get User response shows the book present in the books array. | Pass | |
| TC-016 | Add Book to Collection | Verify the request fails when the ISBN is invalid | Negative | High | A registered user and valid token exist. | 1) Send a POST request to /BookStore/v1/Books with the user's ID and an ISBN that does not exist in the catalogue. 2) Attach a valid token to the Authorization header. 3) Submit the request. | 400 status; error message returned; book is not added. | Pass | |
| TC-017 | Add Book to Collection | Verify the request fails when no token is attached | Negative (auth) | High | A registered user exists; a valid ISBN is known. | 1) Send a POST request to /BookStore/v1/Books with the user's ID and a valid ISBN in the body. 2) Do not attach an Authorization header. 3) Submit the request. | 401 status; book is not added. | Pass | |
| TC-018 | Add Book to Collection | Verify the request fails when the ISBN is already present in the user's collection | Negative (business rule) | Medium | A book has already been added to the user's collection. | 1) Send a POST request to /BookStore/v1/Books using the same user ID and the same ISBN already present in the collection. 2) Attach a valid token to the Authorization header. 3) Submit the request. | Not documented in Swagger — confirm live (candidate finding). | Pass | |
| TC-019 | Replace Book | Verify a book can be replaced with a valid new ISBN | Positive | High | A book exists in the user's collection; a second valid ISBN is known. | 1) Send a PUT request to /BookStore/v1/Books/{ISBN} using the existing ISBN in the path. 2) Include the user's ID and the new ISBN in the body. 3) Attach a valid token to the Authorization header. 4) Submit the request. 5) Send a follow-up GET request to /Account/v1/User/{UUID} to verify the collection. | 200 status; follow-up Get User response shows the new ISBN present and the old ISBN removed. | Pass | |
| TC-020 | Replace Book | Verify the request fails when the new ISBN does not exist | Negative | Medium | A book exists in the user's collection. | 1) Send a PUT request to /BookStore/v1/Books/{ISBN} using the existing ISBN in the path. 2) Include the user's ID and an ISBN that does not exist in the body. 3) Attach a valid token to the Authorization header. 4) Submit the request. | 400 status; error message returned; original book remains unchanged in the collection. | Pass | |
| TC-021 | Replace Book | Verify the request fails when the target ISBN is not in the user's collection | Negative | Medium | A registered user exists; a valid ISBN not currently in their collection is known. | 1) Send a PUT request to /BookStore/v1/Books/{ISBN} using an ISBN not present in the user's collection. 2) Include the user's ID and a different valid ISBN in the body. 3) Attach a valid token to the Authorization header. 4) Submit the request. | Error response (confirm status code live); collection remains unchanged. | Pass | |
| TC-022 | Delete Book | Verify a book in the user's collection can be deleted | Positive | High | A book exists in the user's collection. | 1) Send a DELETE request to /BookStore/v1/Book with the user's ID and the book's ISBN in the body. 2) Attach a valid token to the Authorization header. 3) Submit the request. 4) Send a follow-up GET request to /Account/v1/User/{UUID} to verify the collection. | 204 status; follow-up Get User response confirms the book is no longer present. | Pass | |
| TC-023 | Delete Book | Verify the request fails when the book is not in the user's collection | Negative | Medium | A registered user exists; a valid ISBN not currently in their collection is known. | 1) Send a DELETE request to /BookStore/v1/Book with the user's ID and an ISBN not present in their collection. 2) Attach a valid token to the Authorization header. 3) Submit the request. | 400 status; error message returned. | Pass | |
| TC-024 | Delete All Books | Verify all books can be removed from a user's collection | Positive | High | At least one book exists in the user's collection. | 1) Send a DELETE request to /BookStore/v1/Books with the user's ID as a query parameter. 2) Attach a valid token to the Authorization header. 3) Submit the request. 4) Send a follow-up GET request to /Account/v1/User/{UUID} to verify the collection. | 204 status; follow-up Get User response shows an empty books array. | Pass | |
| TC-025 | Delete All Books | Verify the request fails when no token is attached | Negative (auth) | Medium | A registered user exists with at least one book in their collection. | 1) Send a DELETE request to /BookStore/v1/Books with the user's ID as a query parameter. 2) Do not attach an Authorization header. 3) Submit the request. | 401 status; collection remains unchanged. | Pass | |
| TC-026 | Delete User | Verify a user can be deleted with a valid token | Positive | High | A registered user and valid token exist. | 1) Send a DELETE request to /Account/v1/User/{UUID} using the user's UUID. 2) Attach a valid token to the Authorization header. 3) Submit the request. 4) Send a follow-up GET request to the same UUID to confirm deletion. | 204 status on delete; follow-up Get User request fails, confirming the user no longer exists. | Pass | |
| TC-027 | Delete User | Verify the request fails when no token is attached | Negative (auth) | Medium | A registered user exists. | 1) Send a DELETE request to /Account/v1/User/{UUID} using a valid user's UUID. 2) Do not attach an Authorization header. 3) Submit the request. | 401 status; user is not deleted. | Pass | |
